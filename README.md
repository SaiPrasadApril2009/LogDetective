\# Log Detective v1.0



A beginner-friendly Python defensive

cybersecurity project.



\## Features

\- Reads sample login logs

\- Detects failed login attempts

\- Counts failures by IP address

\- Flags repeated failed attempts

\- Generates a security report



\## Requirements

\- Python 3

\- Windows, Linux or macOS



\## Run

python detective.py



\## Disclaimer

Uses sample logs for educational purposes.

It does not monitor real systems.
